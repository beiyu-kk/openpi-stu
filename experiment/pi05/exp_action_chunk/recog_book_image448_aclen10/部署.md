# recognize_book_name：448×448、action chunk 10 部署

本实验使用非 RTC pi0.5 全量微调配置 `pi05_piper_ft_image448_aclen10_at3_s5`。
模型图像输入为 448×448，每次输出 10 步 Piper 动作。部署配置必须与训练一致。

## 准备 checkpoint

将训练输出中的具体 step 目录复制到部署机器，保留整个目录结构。
默认 10000 步训练的最终 step 为 `9999`，以下示例使用：

```text
/media/ubun/16T/checkpoints/openpi-stu/recog_book_image448_aclen10/9999/
├── params/
└── assets/
    └── recognize_book_name/
        └── norm_stats.json
```

`--policy.dir` 指向包含 `params/` 和 `assets/` 的 step 目录。
如实际保存步数或部署路径不同，请修改该参数。`--policy.asset-id` 与训练时的
`--dataset-repo-id` 一致。

## 启动推理服务

在仓库根目录、已配置好的运行环境中执行：

```bash
XLA_PYTHON_CLIENT_MEM_FRACTION=0.95 uv run --no-sync scripts/serve_policy.py \
    --port=8000 \
    policy:checkpoint \
    --policy.config=pi05_piper_ft_image448_aclen10_at3_s5 \
    --policy.dir=/media/ubun/16T/checkpoints/openpi-stu/recog_book_image448_aclen10/9999 \
    --policy.asset-id=recognize_book_name
```

图像由服务端按训练配置处理为 448×448；真机端发送原始相机图像即可。
Attention bias 仅用于训练，推理时无需提供 bbox 标注。

## 启动真机

首先配置 `can0`：

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
```

按实际设备修改相机序列号；若服务端在其他机器，修改 `--host`。
使用 `examples/piper/main.py` 按动作块执行，设置 `--open-loop-horizon=10`。
每块含 10 步动作，30 Hz 时动作播放时间约为 0.33 秒，之后等待下一次推理返回。

### 夹爪二值化

```bash
uv run --no-sync examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the book titled 《吕思勉文选》 and place it in the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=10 \
    --control-hz=30
```

### 夹爪二值化（重映射）

```bash
uv run --no-sync examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the book titled 《吕思勉文选》 and place it in the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=10 \
    --gripper-closed-mm=0 \
    --gripper-open-mm=50 \
    --control-hz=30
```

### 夹爪连续控制

```bash
uv run --no-sync examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the book titled 《吕思勉文选》 and place it in the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=10 \
    --control-hz=30 \
    --no-binarize-gripper
```

本配置没有 RTC 训练，使用上述同步控制入口。控制端的 `open-loop-horizon` 不得超过 10，
因为模型返回的动作块长度为 10；`--control-hz=30` 是播放频率，与动作块长度分别设置。
