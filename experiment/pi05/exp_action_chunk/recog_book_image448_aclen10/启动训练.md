# recognize_book_name：448×448、action chunk 10 训练

本实验参考 `experiment/pi05/exp_at_bias/recog_book_448`，用于对比动作块长度从 30 改为 10 的效果。
沿用该基线的非 RTC 全量微调、book bbox attention bias（`at3_s5`）和训练超参数。

## 实验配置

TrainConfig 定义在 `src/openpi/training/configs/pi0.py`（当前 pi0 / pi0.5 配置文件），
通过 `openpi.training.config.get_config()` 注册入口读取。

| 项目 | 配置 |
| --- | --- |
| 配置名称 | `pi05_piper_ft_image448_aclen10_at3_s5` |
| 实验名称 | `recog_book_image448_aclen10` |
| 模型 | pi0.5，全量微调 |
| 图像尺寸 | `image_resolution=(448, 448)`，`resize_with_pad` |
| 动作块长度 | `action_horizon=10` |
| 区域标注 | `--region-annotation-mode book` |
| Attention bias | scale 为 5，query types 为 `action`、`image`、`prompt` |
| RTC | 未启用，`training_rtc=None` |
| Batch size / 训练步数 | 32 / 10000 |
| 学习率 | warmup 500 步，peak `1e-5`，decay 10000 步，末值 `1e-6` |
| Checkpoint | 每 1000 步保存，`keep_period=5000` |
| EMA | `None` |

`action_horizon=10` 同时控制训练数据中的动作序列长度和模型预测长度。
真机端的 `--open-loop-horizon=10` 只控制每次执行多少步，不能代替训练配置中的 `action_horizon`。

## 环境准备

以下命令均在 `openpi-stu` 仓库根目录执行。先按项目训练环境文档准备好 `.venv`，再激活：

```bash
source .venv/bin/activate
```

可选：使用独立 tmux 会话运行训练。

```bash
tmux new -s openpi
```

按 `Ctrl+b` 后按 `d` 脱离会话，恢复会话使用：

```bash
tmux attach -t openpi
```

默认启用 W&B，可使用自己的账号登录：

```bash
uv run --frozen wandb login
```

如不使用 W&B，在训练命令末尾添加 `--no-wandb-enabled`。

### TorchCodec / FFmpeg

如尚未配置 FFmpeg 运行库，可沿用基线实验的环境：

```bash
conda create -y \
  -p "$PWD/.ffmpeg-runtime" \
  -c conda-forge \
  "ffmpeg=6"
```

已有 `.ffmpeg-runtime` 时直接加载，无需重复创建：

```bash
export LD_LIBRARY_PATH="$PWD/.ffmpeg-runtime/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"

uv run --frozen python -c \
  "from torchcodec.decoders import VideoDecoder; print('TorchCodec OK')"
```

## 启动训练

以下路径沿用 `exp_at_bias/recog_book_448` 的机器环境示例，请按实际机器调整
数据集、base 模型和输出路径，以及 `CUDA_VISIBLE_DEVICES`。
数据集需要包含 `meta/info.json`、`data/` 和内嵌 bbox 标注；该配置启用区域 bias，
启动器会检查标注字段是否存在。

```bash
CUDA_VISIBLE_DEVICES=2,3,4,5 XLA_PYTHON_CLIENT_MEM_FRACTION=0.95 uv run --frozen scripts/train_piper.py \
  --config pi05_piper_ft_image448_aclen10_at3_s5 \
  --dataset-dir /data/zixian_guo/projects/haoming/project/PI/riri/project/dataset/recongnize_one_book_new_ab \
  --dataset-repo-id recognize_book_name \
  --region-annotation-mode book \
  --exp-name recog_book_image448_aclen10 \
  --base-model-dir /data/zixian_guo/projects/haoming/project/PI/riri/pi05_base/pi05_base/params \
  --checkpoint-dir /data/zixian_guo/projects/haoming/project/PI/riri/project/output/checkpoints/recog_book_image448_aclen10 \
  --norm-stats-dir ./assets/pi05_piper_ft_image448_aclen10_at3_s5/recognize_book_name \
  --compute-norm-stats
```

- `--norm-stats-dir` 使用本实验独立目录，让首次运行按 10 步动作序列计算统计量。
  `--compute-norm-stats` 仅在统计量缺失时计算；已有文件会被复用。
- 新实验从 pi05 base 参数初始化，配置中的 `resize_siglip_posemb=True` 适配 448 图像尺寸。
- 默认 batch size 为 32；显存不足时可用 `--batch-size` 调整，并保证能被可见设备数整除。
- 首次训练使用新的输出目录。续训时在同一命令末尾添加 `--resume`，保持配置、数据集、
  统计量目录和 checkpoint 目录一致。只有明确要重新训练并覆盖该目录时才添加 `--overwrite`，
  它与 `--resume` 互斥。30 步基线 checkpoint 不用作本实验的 `--resume`。
- 默认训练 10000 步，最后保存的 step 为 `9999`。部署时选择具体 step 目录，
  并保留其中的 `params/` 与 `assets/recognize_book_name/norm_stats.json`。

## 启动前检查配置

以下命令只读取配置和输入规格，不启动训练或加载模型权重：

```bash
uv run --frozen python - <<'PY'
from openpi.training import config

cfg = config.get_config("pi05_piper_ft_image448_aclen10_at3_s5")
assert cfg.model.pi05
assert cfg.model.image_resolution == (448, 448)
assert cfg.model.action_horizon == 10
assert cfg.training_rtc is None
observation, actions = cfg.model.inputs_spec()
print("config:", cfg.name)
print("image:", observation.images["base_0_rgb"].shape)
print("model actions:", actions.shape)
print("region guidance:", cfg.model.region_guidance)
PY
```

模型内部动作维度保持基线的填充维度；Piper 输出变换后，真机收到的动作块形状为 `(10, 7)`。
部署命令见同目录 `部署.md`。
