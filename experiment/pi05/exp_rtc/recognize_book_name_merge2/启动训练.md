
启动训练

```bash
CUDA_VISIBLE_DEVICES=4,5,6,7 XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run --frozen scripts/train_piper.py \
  --config pi05_piper_full_finetune_rtc_d9_r448_at_bias_s5_merge2 \
  --dataset-dir /data/zixian_guo/projects/haoming/project/PI/riri/project/dataset/recognize_book_name_at_bias \
  --dataset-repo-id recognize_book_name \
  --region-annotation-mode book \
  --exp-name recognize_book_rtc_d9_r448_merge2_at_bias_s5 \
  --base-model-dir /data/zixian_guo/projects/haoming/project/PI/riri/pi05_base/pi05_base/params \
  --checkpoint-dir /data/zixian_guo/projects/haoming/project/PI/riri/project/output/checkpoints/recognize_book_rtc_d9_r448_merge2_at_bias_s5 \
  --compute-norm-stats \
  --overwrite
```

## 参数说明

路径参数：

- `exp-name`：实验名称
- `dataset-repo-id`：数据集代号
- `base-model-dir`：base 模型路径
- `checkpoint-dir`：模型输出路径
- `dataset-dir`：数据集路径


训练参数：

- `--config pi05_piper_full_finetune_rtc_attention_bias_448_d9_scale_{0_5,2,5}` 分别选择 448 分辨率、delay-9 的三种区域 bias scale。
- `--region-guidance` 只用于给普通配置临时启用区域偏置，或覆盖命名配置的默认 bias 参数。
- `--config= 直接选择 `src/openpi/training/config.py` 中的 TrainConfig，例如 `pi05_piper_full_finetune` 或 `pi05_piper_lora_finetune`。_image448
- `--resume` 必须使用与已有 checkpoint 一致的训练策略和图像尺寸；448 的 checkpoint 不能作为 224 的续训。
