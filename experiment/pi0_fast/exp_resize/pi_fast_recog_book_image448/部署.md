# pi0-fast recognize_book_name 448×448 部署

## 启动推理

部署时使用训练时相同的 pi0-fast 配置和图像尺寸：

```bash
XLA_PYTHON_CLIENT_MEM_FRACTION=0.95 uv run --no-sync scripts/serve_policy.py \
    --port=8000 \
    policy:checkpoint \
    --policy.config=pi0_fast_piper_full_finetune_image448 \
    --policy.dir=/media/ubun/16T/checkpoints/openpi-stu/pi_fast_recog_book_image448/9999
```

训练最终步若为 `9999`，对应目录使用 `/9999`；如实际结束步数或保存位置不同，请改成已有 checkpoint 目录。
pi0-fast checkpoint 使用 FAST tokenizer 和 pi0-fast 模型配置，不要用 pi05 配置加载。

## 启动真机

首先启动 `can0`：

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
```

检查并替换为实际 Piper 设备的相机序列号，再启动控制：

```bash
uv run --no-sync examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the book titled 《吕思勉文选》 and place it in the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=30 \
    --control-hz=30
```

模型每次预测 30 帧动作；该配置不是 RTC 模型，控制端按一个完整动作块执行后再请求下一块。
夹爪二值化或连续控制可按 `examples/piper/main.py --help` 中的选项配置。
