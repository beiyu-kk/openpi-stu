# pi0-fast recognize_book_name 448×448 全量微调

本实验使用 pi0-fast base，在 Piper `recognize_book_name` 数据集上进行全量微调。输入分辨率为
448×448，动作块长度为 30 帧。pi0-fast 使用 FAST 离散动作 token；本实验不启用 RTC。

## 开启 tmux

创建会话：

```bash
tmux new -s pi0fast-book-448
```

脱离会话：

```text
Ctrl+b  d
```

重新进入会话：

```bash
tmux attach -t pi0fast-book-448
```

## 设置临时 wandb

在当前 shell 中设置你自己的 WandB API key：

```bash
export WANDB_API_KEY='<your-wandb-api-key>'
```

## ffmpeg 库处理方法

如果当前 conda 环境尚未安装 ffmpeg，可在仓库目录创建运行时环境：

```bash
conda create -y \
  -p "$PWD/.ffmpeg-runtime" \
  -c conda-forge \
  "ffmpeg=6"
```

在当前 shell 中使用该库并检查 TorchCodec：

```bash
export LD_LIBRARY_PATH="$PWD/.ffmpeg-runtime/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
uv run --frozen python -c \
  "from torchcodec.decoders import VideoDecoder; print('TorchCodec OK')"
```

## 启动训练

激活 uv 环境：

```bash
source .venv/bin/activate
```

启动 pi0-fast 448×448 全量微调：

```bash
CUDA_VISIBLE_DEVICES=2,3,4,5 XLA_PYTHON_CLIENT_MEM_FRACTION=0.95 uv run --frozen scripts/train_piper.py \
  --config=pi0_fast_piper_full_finetune_image448 \
  --dataset-dir /data/zixian_guo/projects/haoming/project/PI/riri/project/dataset/recongnize_one_book_new_ab \
  --dataset-repo-id recognize_book_name \
  --exp-name pi_fast_recog_book_image448 \
  --checkpoint-dir /media/ubun/16T/checkpoints/openpi-stu/pi_fast_recog_book_image448 \
  --batch-size 32 \
  --compute-norm-stats \
  --overwrite
```

未传 `--base-model-dir` 时使用配置默认的 `gs://openpi-assets/checkpoints/pi0_fast_base/params`。
448 分辨率会显著增加视觉 token 数和显存占用，先用小 batch 验证资源情况。训练使用全量微调；
如需改用 LoRA，将配置名换成 `pi0_fast_piper_lora_finetune_image448` 并单独设置实验名与 checkpoint 路径。
若使用 640×480 相机输入且需保留原始像素，请选 `pi0_fast_piper_full_finetune_image640` 配置；该配置会在上下各补 80 行，得到 640×640 输入。
若要求所有输入都只补边、不允许缩放，使用 `pi0_fast_piper_full_finetune_image640_pad_only`；图像任一边超过 640 时会报错。
该模式使用配置中固定的 640×640 画布，小图也只居中补边。训练时关闭裁剪、缩放和旋转增强，保留颜色增强。
需要更大的画布时，新增 train config，设置对应的 `image_resolution` 和 `image_resize_mode="pad_only"`；部署使用同名配置。

## 参数说明

路径和实验参数：

- `--dataset-dir`：本地 LeRobot 数据集路径。
- `--dataset-repo-id`：数据集代号，用于 checkpoint 中的归一化资产目录。
- `--exp-name`：实验名称。
- `--checkpoint-dir`：训练 checkpoint 输出目录。
- `--base-model-dir`：可选；不传时从配置中的 pi0-fast base checkpoint 初始化。

模型参数：

- `--config pi0_fast_piper_full_finetune_image448`：选择注册的 448×448 pi0-fast Piper 全量微调配方。
- `pi0_fast_piper_full_finetune_image640_pad_only`：640×640 纯 padding 配方，不缩放输入，较大的图像会被拒绝。
- `--batch-size 1`：降低 448 分辨率下的显存占用，可按实际资源调整。
- 该配方的 `action_horizon` 为 30；pi0-fast 训练预测 FAST 动作 token，不使用连续动作 flow loss。
- 本实验没有 RTC 训练支持，不要给该配置添加 RTC 参数。

从 224 pi0-fast base 初始化时，权重加载器会插值 SigLIP 图像位置嵌入到 448 对应的 patch 网格。
分辨率改变应启动新训练；续训时保持相同的配置、分辨率和 checkpoint。
