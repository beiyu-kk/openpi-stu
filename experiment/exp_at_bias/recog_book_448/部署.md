## 启动推理

1. 修改 policy.config 为目标config，注意是否为lora

2. 修改 policy.dir 为目标checkpoint的路径

```bash
XLA_PYTHON_CLIENT_MEM_FRACTION=0.95 uv run --no-sync scripts/serve_policy.py \
    --port=8000 \
    policy:checkpoint \
    --policy.config=pi05_piper_ft_image448_at3_s5 \
    --policy.image-size=448 \
    --policy.dir=/media/ubun/16T/checkpoints/openpi-stu/recog_book_448_ab3_s5
```

## 启动真机

首先要启动 can0 端口

```bash
# can0 up
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
```

注意设置相机的序列号。该 checkpoint 未使用 RTC 训练，真机控制使用 `main.py` 按动作块执行。
模型每次返回 30 步动作；以下命令以 30 Hz 执行完整动作块后再请求下一块。

夹爪二值化

```bash
uv run --no-sync examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the book titled 《吕思勉文选》 and place it in the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=30 \
    --control-hz=30
```

夹爪二值化(重映射)

```bash
uv run --no-sync examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the book titled 《吕思勉文选》 and place it in the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=30 \
    --gripper-closed-mm=0 \
    --gripper-open-mm=50 \
    --control-hz=30
```
