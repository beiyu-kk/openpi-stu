LoRA 微调：

```bash
CUDA_VISIBLE_DEVICES=0 CUDA_XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run --no-sync scripts/train_piper.py \
    --config pi05_piper_lora_finetune \
    --dataset-dir /media/ubun/16T/Dataset/piper_eva_data/recognition/recognize_red_stripe_book_100/success \
    --dataset-repo-id recognize_book_label_color_1_region_bias \
    --base-model-dir /media/ubun/16T/checkpoints/openpi/openpi-assets/checkpoints/pi05_base/params \
    --checkpoint-dir /media/ubun/16T/checkpoints/openpi/recognize_red_stripe_book_224 \
    --exp-name recognize_red_stripe_book_224 \
    --batch-size 32 \
    --num-train-steps 20000 \
    --compute-norm-stats \
    --resume
```

- `--region-guidance` 可以用来启动区域偏置
- `--config ` 选择不同的训练策略

    'pi05_piper_lora_finetune', 

    'pi05_piper_full_finetune_336',
