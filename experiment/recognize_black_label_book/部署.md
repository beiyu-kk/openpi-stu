# piper 部署

## 环境安装

```bash
conda create -y -n piper-openpi python=3.10
conda activate piper-openpi

pip install --no-deps -e packages/openpi-client
pip install tyro dm-tree msgpack websockets opencv-python pillow
pip install -e /home/ubun/project/piper/data_collection/piper_data_collection/thirdparty/piper_sdk
pip install pyrealsense2
```

## 启动推理

1. 修改 policy.config 为目标config，注意是否为lora

2. 修改 policy.dir 为目标checkpoint的路径

```bash
XLA_PYTHON_CLIENT_MEM_FRACTION=0.95 uv run --no-dev scripts/serve_policy.py \
    --port=8000 \
    policy:checkpoint \
    --policy.config=pi05_piper_lora_finetune \
    --policy.dir=/media/ubun/16T/checkpoints/openpi/piper_book_color/book_color_lora/9999/
```

## 启动真机

首先要启动 can0 端口

```bash
# can0 up
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
```

注意设置相机的序列号

夹爪二值化

```bash
python examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Pick up the book labeled "王国维文选" and place it into the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=30 \
    --control-hz=30
```

夹爪二值化(重映射)

```bash
python examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Pick up the black book and place it into the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --can-name=can0 \
    --open-loop-horizon=15 \
    --gripper-closed-mm=0 \
    --gripper-open-mm=40 \
    --control-hz=15
```
