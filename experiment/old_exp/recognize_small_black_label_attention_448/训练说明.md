这次实现的是你选定的“训练期标注引导，后期撤除”方案：

- 保留原有图像、指令、状态、动作和归一化处理链，额外附加黑标签掩码。
- 掩码与图像同步缩放、补边、裁剪和旋转，再转换成 patch 覆盖比例。
- 只给选定层、选定头的**动作 token → 图像 token**注意力增加偏置。
- 不增加辅助损失或模型参数。无效标注不加偏置，动作样本照常参与训练。
- 推理始终不使用标注，新方法训练出的权重可以通过原来的匹配配置加载。

默认日程如下：

| 训练阶段 | 引导概率 | 偏置强度 |
|---|---:|---:|
| 前 30% | 50% | 0.5 |
| 30%～70% | 逐渐降到 0 | 逐渐降到 0 |
| 最后 30% | 0 | 0 |

对于当前 pi0.5，默认作用于第 **8、9 层**的第 **0、1 个查询头**，编号从 0 开始。
