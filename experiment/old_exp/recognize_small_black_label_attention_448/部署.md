## 启动真机

首先要启动 can0 端口

```bash
# can0 up
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
```

注意设置相机的序列号

夹爪二值化

```bash
python examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Pick up the book labeled "王国维文选" and place it into the black grid on the right.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=30 \
    --control-hz=30
```

夹爪二值化(重映射)

```bash
python examples/piper/main.py \
    --host=127.0.0.1 \
    --port=8000 \
    --prompt='Retrieve the red book whose spines are decorated with small red stripes.' \
    --head-camera-serial=339322074804 \
    --wrist-camera-serial=346522074547 \
    --show-cameras \
    --can-name=can0 \
    --open-loop-horizon=30 \
    --gripper-closed-mm=0 \
    --gripper-open-mm=50 \
    --control-hz=15
```

夹爪连续控制

``` bash
python examples/piper/main.py \
    --host=127.0.0.1 \

    --no-binarize-gripper
```
