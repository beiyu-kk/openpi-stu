LoRA 微调：
   
```bash
CUDA_VISIBLE_DEVICES=0 XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run --no-sync scripts/train_piper.py \
    --config pi05_piper_lora_finetune \
    --image-size 224 \
    --batch-size 32 \
    --num-train-steps 10000 \
    --compute-norm-stats \
    --exp-name pick_chinese_chess_224 \
    --dataset-repo-id pick_chinese_chess_224 \
    --base-model-dir /media/ubun/16T/checkpoints/openpi/openpi-assets/checkpoints/pi05_base/params \
    --checkpoint-dir /media/ubun/16T/checkpoints/openpi/pick_chinese_chess_224 \
    --dataset-dir /media/ubun/16T/Dataset/piper_eva_data/recognition/pick_chinese_chess/success \
    --resume
```

路径参数：
- `exp-name`：实验名称
- `dataset-repo-id`：数据集代号
- `base-model-dir`：base 模型路径
- `checkpoint-dir`：模型输出路径
- `dataset-dir`：数据集路径


训练参数：

- `--region-guidance` 可以用来启动区域偏置
- `--config` 直接选择 `src/openpi/training/config.py` 中的 TrainConfig，例如 `pi05_piper_full_finetune` 或 `pi05_piper_lora_finetune`。
- `--image-size` 独立指定图像边长，例如 224、336、448；不传时两个 Piper 配置均默认 224。
- `--resume` 必须使用与已有 checkpoint 一致的训练策略和图像尺寸；448 的 checkpoint 不能作为 224 的续训。


Training RTC：

- 普通训练继续使用 `pi05_piper_full_finetune` / `pi05_piper_lora_finetune`。
- 全量 RTC 使用 `--config pi05_piper_full_finetune_rtc`。
- 动作侧 LoRA RTC 使用 `--config pi05_piper_lora_finetune_rtc`。
- RTC 的 delay、loss、划分和验证参数统一配置在 `TrainConfig.training_rtc` 中。
- 首次运行使用新的 `--checkpoint-dir` 和 `--exp-name`，移除旧命令的 `--resume`，保留 `--compute-norm-stats`。
  RTC 默认另建训练集统计目录；不要把旧的全数据 norm_stats 直接当成 RTC 训练集统计。
- 已有模型转 RTC 时，把旧 checkpoint 的 `params` 传给 `--base-model-dir`，新实验创建新的优化器状态。

完整配置、LoRA／全量差异及推理前缀协议见 [Training RTC 文档](../../docs/training_rtc.md)。
