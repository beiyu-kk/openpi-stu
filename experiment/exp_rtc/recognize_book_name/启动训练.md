# recognize_book_name RTC 训练

## 带 book bbox attention bias 的全量微调

标注字段已经直接写入 `success/origin` 的 LeRobot episode parquet。训练直接读取
`origin`，不需要 sidecar 或标注目录参数。首次训练不要添加 `--resume`：

```bash
CUDA_VISIBLE_DEVICES=0 XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run --frozen scripts/train_piper.py \
    --config pi05_piper_full_finetune_rtc_attention_bias \
    --image-size 448 \
    --dataset-dir /media/ubun/16T/Dataset/piper_eva_data/recognition/recognize_book_name/success/origin \
    --dataset-repo-id recognize_book_name \
    --region-annotation-mode book \
    --exp-name recognize_book_book_bias_448 \
    --base-model-dir /media/ubun/16T/checkpoints/openpi/openpi-assets/checkpoints/pi05_base/params \
    --checkpoint-dir /media/ubun/16T/checkpoints/openpi/recognize_book_book_bias_448 \
    --compute-norm-stats
```

`pi05_piper_full_finetune_rtc_attention_bias` 已经启用区域引导，不需要再传
`--region-guidance`。把 `book` 改成 `title` 或 `both` 可以选择书名框或两类框并集，
同时应使用新的 `exp-name` 和 `checkpoint-dir`。

字段位置、转换方法和查看命令见
[`docs_piper/annotation_adapter.md`](../../../docs_piper/annotation_adapter.md)，完整训练机制见
[`docs_piper/rtc_attention_bias_training.md`](../../../docs_piper/rtc_attention_bias_training.md)。

## 不带 attention bias 的 RTC 基线

```bash
CUDA_VISIBLE_DEVICES=0 XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run --frozen scripts/train_piper.py \
    --config pi05_piper_full_finetune_rtc \
    --image-size 224 \
    --batch-size 32 \
    --num-train-steps 20000 \
    --compute-norm-stats \
    --exp-name recognize_book_name_rtc \
    --dataset-repo-id recognize_book_name_rtc \
    --base-model-dir /media/ubun/16T/checkpoints/openpi/openpi-assets/checkpoints/pi05_base/params \
    --checkpoint-dir /media/ubun/16T/checkpoints/openpi/recognize_book_name_rtc \
    --dataset-dir /media/ubun/16T/Dataset/piper_eva_data/recognition/recognize_book_name/success/origin \
    --resume
```

## 参数说明

路径参数：

- `exp-name`：实验名称
- `dataset-repo-id`：数据集代号
- `base-model-dir`：base 模型路径
- `checkpoint-dir`：模型输出路径
- `dataset-dir`：数据集路径


训练参数：

- `--config pi05_piper_full_finetune_rtc_attention_bias` 启用当前 RTC 区域偏置方案。
- `--region-guidance` 只用于给普通配置临时启用区域偏置，或覆盖命名配置的默认 bias 参数。
- `--config` 直接选择 `src/openpi/training/config.py` 中的 TrainConfig，例如 `pi05_piper_full_finetune` 或 `pi05_piper_lora_finetune`。
- `--image-size` 独立指定图像边长，例如 224、336、448；不传时两个 Piper 配置均默认 224。
- `--resume` 必须使用与已有 checkpoint 一致的训练策略和图像尺寸；448 的 checkpoint 不能作为 224 的续训。
